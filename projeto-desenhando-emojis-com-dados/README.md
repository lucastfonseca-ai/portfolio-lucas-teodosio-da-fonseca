# 🎛️ Projeto Multiestrutural: Emojis, Matrizes Musicais e Integração

## 📝 Descrição do Projeto
Este projeto reúne três desafios computacionais distintos, unidos por um tema em comum: **manipulação de estruturas de dados complexas utilizando Python** (listas, dicionários e tuplas em múltiplos níveis).

Desenvolvido como atividade prática, o sistema explora conceitos fundamentais como:
- Iteração em múltiplos níveis (loops aninhados)
- Imutabilidade de estruturas
- Transformações de dados
- Manipulação de matrizes

Os três módulos que compõem o projeto são:

### 😀 1. Criador de Emojis (Pixels RGB)
Simula a construção e modificação de um emoji a partir de uma grade de pixels RGB. O sistema percorre cada pixel e aplica uma transformação de brilho seletiva, respeitando a imutabilidade das tuplas.

Além disso, o resultado é exibido visualmente utilizando a biblioteca **Matplotlib**, transformando dados em imagem.

---

### 🎵 2. Biblioteca Musical (Matrizes e Transposição)
Trabalha com uma estrutura que simula uma biblioteca de sons organizada em matrizes.

O algoritmo realiza:
- Percurso em múltiplos níveis (lista → dicionário → matriz)
- **Transposição de matrizes** (linhas viram colunas)
- Conversão de listas para tuplas para manter consistência estrutural

Esse módulo reforça conceitos matemáticos aplicados à programação.

---

### 🔗 3. Integrador (Manipulação Dinâmica de Dados)
Um módulo mais livre e criativo que integra conceitos dos anteriores.

Funcionalidades:
- Inserção dinâmica de elementos (`insert`)
- Remoção de elementos (`pop`)
- Transformação de dados (inversão de cores)
- Percurso profundo em estruturas aninhadas

Simula uma espécie de "playlist visual", onde frames são manipulados como se fossem animações baseadas em pixels.

---

## 🚀 Tecnologias Utilizadas

- **Linguagem:** Python  
- **Bibliotecas:** Matplotlib (visualização de imagem)
- **Ambiente:** Notebook

## 📊 Resultados e Aprendizados

O projeto reforça habilidades essenciais em programação estruturada e manipulação de dados:

- 🧠 **Pensamento lógico:** Aplicação de loops aninhados em múltiplos níveis
- 🔄 **Transformação de estruturas:** Modificação de dados respeitando restrições como imutabilidade
- 🧩 **Organização de dados:** Uso eficiente de listas, tuplas e dicionários
- 🎨 **Visualização:** Representação gráfica de dados RGB com Matplotlib
- 📐 **Aplicação matemática:** Implementação de transposição de matrizes
