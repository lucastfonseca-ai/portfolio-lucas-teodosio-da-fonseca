# 🧠 Coleção de Algoritmos em Python (Baseados em Portugol)

## 📝 Descrição do Projeto
Este repositório reúne uma série de algoritmos desenvolvidos em **Python**, originalmente concebidos a partir de pseudocódigos em **Portugol**, com foco em lógica de programação e resolução de problemas do cotidiano.
O projeto foi estruturado como um conjunto de funções independentes, cada uma abordando um cenário prático distinto, como processamento de vendas, análise climática, gestão de notas acadêmicas e simulação financeira.
O principal objetivo é demonstrar a transição de lógica algorítmica (Portugol) para uma linguagem de programação real (Python), reforçando conceitos fundamentais como:
- Estruturas condicionais
- Laços de repetição
- Entrada e saída de dados
- Validação de dados
- Acumulação e processamento de informações

---

## 📂 Estrutura do Projeto

O projeto é composto pelas seguintes funções principais:

### 🛒 `processar_vendas()`
Simula o processamento de uma compra com múltiplos produtos.
- Recebe nome, preço e quantidade dos itens
- Valida entradas inválidas
- Calcula subtotais e total da compra

### 🌡️ `analisar_clima()`
Realiza uma análise simples de temperaturas ao longo de 7 dias.
- Calcula média semanal
- Conta dias com temperatura elevada (> 35°C)
- Detecta condições climáticas extremas

### 🎓 `sistema_notas_turma()`
Gerencia o desempenho acadêmico de alunos.
- Calcula média de duas notas por aluno
- Classifica em: Aprovado, Recuperação ou Reprovado

### 💰 `simulador_poupanca()`
Simula a evolução de um investimento com aportes mensais.
- Aplica juros compostos mensalmente
- Permite depósitos adicionais
- Exibe saldo atualizado por período
